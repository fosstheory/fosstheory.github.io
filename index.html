02

THE ENGINE UNDERNEATH

One strictly typed TypeScript platform end to end — interface, 3D geometry, pricing and serverless functions — on a multi-tenant PostgreSQL core.

3D Spatial Engine

  • Three.js + React Three Fiber WebGL scene graph
  • Constructive solid geometry — boolean solvers cut pools, steps and seating into terrain live
  • Bidirectional 2D ↔ 3D sync — blueprint plane mirrored into the 3D model
  • Procedural UV mapping at true 1×1 ft texture scale
  • Geospatial imaging — Cesium, Leaflet and aerial tiles for roof tracing and solar layout

Data & Security

  • Multi-tenant PostgreSQL — every record carries a company key
  • Row-level security evaluated on every query, not just in the interface
  • Sealed server procedures — narrow, audited entry points for public visitors
  • Encrypted secrets — provider keys stay server-side, never in the browser
  • Role model — platform admin, company owner, staff, sales, customer

Edge Runtime

  • 40+ serverless functions on a distributed Deno edge runtime
  • Scheduler — timed sends and posts fire every five minutes, browser closed or not
  • Metering engine enforces plan limits, credits and overage
  • Stripe, Twilio, Resend — checkout, voice/SMS/WhatsApp and email in production
  • PDF & print — high-DPI quotes, invoices and signed documents
03

PUBLIC API V1

Prefer to build on it yourself? The same licensed platform, exposed through one simple API.

Public API v1 authenticates with hashed bearer keys, scoped per product and rate limited per plan, with a JavaScript SDK to get moving fast. Keys are issued per company from your own dashboard — your data stays inside your tenant boundary, enforced by the database itself.

// Foss Theory Public API v1
fetch("https://api.fosstheory.com/v1/quotes", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ft_live_…",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ discipline: "pool" })
})
