Developers

Public API v1

Prefer to build on it yourself? The same licensed platform, exposed through one simple API. A Foss Theory-hosted API is on the roadmap.

One key. Every module.

Public API v1 authenticates with hashed bearer keys, scoped per product and rate limited per plan, with a JavaScript SDK. Keys are issued per company from your own dashboard — your data stays inside your tenant boundary, enforced by the database itself.

// Foss Theory · Public API v1
fetch("https://api.fosstheory.com/v1/quotes", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ft_live_…",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ discipline: "pool" })
})
